# Optymalizacja kompletacji zamówień — „Magazyn Centralny Alfa”

Symulacja magazynu e-commerce (dane wyłącznie syntetyczne) z agentem AI, który planuje fale kompletacji,
trasy zbierania i przesunięcia towaru — komunikując się z WMS **wyłącznie** przez własny serwer MCP
z egzekwowaniem uprawnień po stronie serwera.

> Projekt w budowie — pełna dokumentacja pojawi się wraz z kolejnymi kamieniami milowymi (zob. `CHANGELOG.md`).
